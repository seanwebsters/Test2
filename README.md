# Calm Stories + Sleep Stories Studio

All the code lives in [`calm-stories/`](calm-stories/). See [`calm-stories/README.md`](calm-stories/README.md) for setup.

**Deploying on Vercel:** set the project's Root Directory to `calm-stories`.

After changing environment variables in Vercel, redeploy (Deployments → ⋯ → Redeploy) or push any commit so they take effect.

## AIBI

**AIBI — Learn AI. A little every day.** lives in [`aibi/`](aibi/). See [`aibi/README.md`](aibi/README.md). On Vercel, set the Root Directory to `aibi`.

## WAG

**WAG — A little world for your best friend.** A cosy game you play with your real dog, with a built-in Match-3 puzzle game (Treasure Trails). Lives in [`wag/`](wag/). See [`wag/README.md`](wag/README.md). On Vercel, set the Root Directory to `wag`.
