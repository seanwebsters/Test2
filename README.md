# Calm Stories + Sleep Stories Studio · Veloria

This repository holds three projects:

- [`calm-stories/`](calm-stories/) — Calm Stories + Sleep Stories Studio. See [`calm-stories/README.md`](calm-stories/README.md) for setup.
- [`calm-island/`](calm-island/) — Calmlings: Calm Island, a 3D sandbox.
- [`veloria/`](veloria/) — **Veloria**, a cozy romantasy merge adventure. See [`veloria/README.md`](veloria/README.md).

**Deploying on Vercel:** create one Vercel project per app and set its Root Directory to `calm-stories` or `veloria`.

After changing environment variables in Vercel, redeploy (Deployments → ⋯ → Redeploy) or push any commit so they take effect.
